# 当前 baseline 技术摘要

项目已接入原曲转谱、双向选调、YuE2 曲风生成、人声分离、三种换声后端、混音、成品分轨/MIDI 和技术评审。架构及接口分别见 [01](01-architecture.md)、[02](02-contracts.md)。

| 换声方案 | 当前正式能力 | 本机保留的代表模型 |
|---|---|---|
| Seed-VC zero_shot | 通用 F0 歌声模型 + 参考人声 | 44.1 kHz 预训练模型 |
| Seed-VC finetuned | 歌手微调、验证、导出、多候选推理 | 黄绮珊 1000 步及已有其他歌手 |
| so-vits-svc | 歌手训练、单候选推理 | 杨坤 ContentVec768 + RMVPE + 标准 NSF-HiFiGAN，4000+2000 步 |
| RVC | 歌手训练、训练集索引、多候选推理 | 黄绮珊 v2/48k，4000 步 |

SVC 正式预设不启用浅层扩散、增强器或检索；其它 SVC 消融工具在独立 experiments 目录，实验结论见 [19](19_svc_optimization.md)。RVC 项目默认 index_rate=0.5，0.75 对照是单独预设与运行，不修改默认配置。

完整示例使用本机保留的黄绮珊《穿越曙光》《Last Dance》《绿洲》；每首曲风在对应 task config 固定。既有定量比较详见 [RVC 指南](20_rvc.md)。此前杨坤、孙燕姿等实验记录依然保留，但已清理的运行不能作为当前下载入口。

当前限制：专业听感未由自动检查替代；素材仍含有损来源与人声分离误差；生成歌词/发音、转谱准确性、跨音区自然度需要人工验收。新硬件部署仍需独立验证。

工程整理后的交付范围与结果见 [21](21_delivery.md)。此前各轮设计与实测报告保存在 [历史技术报告](archive/07-baseline-report_before_cleanup_20261029.md)，不作为当前默认行为说明。
