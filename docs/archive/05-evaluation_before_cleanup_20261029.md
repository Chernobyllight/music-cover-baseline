评价区分技术完成和效果达标。技术检查用于发现缺失文件、截断、错误采样率、错位和削波；听感评价用于判断风格、歌曲保留程度、音色接近程度与自然度。两类结论分别记录。

每次正式 cover 必须保留三份核心音频，以及换声前后的人声独听文件。

| 标记 | 内容 | 主要比较目的 |
| --- | --- | --- |
| A | YuE2 生成的完整歌曲 | 判断风格改变、旋律与歌词保留 |
| B | 未换声的人声与分离伴奏直接重混 | A／B 暴露分离、重采样和电平处理的损伤 |
| C | 转换后人声混回同一伴奏 | B／C 判断换声音色、自然度与对齐 |

原曲另作为旋律与内容参考，目标人物录音另作为音色参考。不能用目标人物参考录音的音高评价新歌曲是否唱准。

正式归档音频保存原始电平。听感比较可以生成独立试听副本，在相同完整区间使用整体增益匹配响度，避免把“更响”误认为“更好”；保存所用增益，不对试听文件做额外压缩或去噪。

首版技术检查按以下标准执行。数值阈值是本项目的初始工程目标，不是上游模型的性能承诺。

| 检查项 | 首版规则 | 不通过时的动作 |
| --- | --- | --- |
| 文件与数值 | 所有必需产物存在、可解码，采样值无 NaN 或 Inf，非空 | 阶段失败，不进入下游 |
| 输出规格 | 最终 48 kHz 立体声 WAV，metadata 与真实文件一致 | 检查格式转换与写出 |
| 时长 | 最终帧数等于选定 cover 主文件的帧数 | 定位长度策略；不自动掩盖中间漂移 |
| 生成完整性 | 无明显截断，段落和歌词顺序经核对 | 重查谱词或重新生成 |
| 对齐 | 至少检查开头、中间、结尾；残余偏移超过 20 ms 标记复核 | 分辨固定延迟与累积漂移；20 ms 内仍需听感检查 |
| 静音与停顿 | 原有句间间隔未被压缩或删除，纯伴奏段无明显伪人声 | 检查切片、F0 和转换输出 |
| 峰值 | 最终输出以不高于 -1 dBTP 为初始目标 | 使用明确工具测 true peak；记录整体衰减或限制器 |
| 可追溯性 | 输入哈希、权重身份、参数、阶段耗时齐全 | 结果可保留试听，但标为复现记录不完整 |

峰值规范中的 dBTP 指 true peak，不能直接用最大采样值冒充。若首版尚未实现 true peak 测量，应将该字段标为未测，并另记 sample peak。

客观指标只做辅助，不用单一分数替代听感。

| 指标 | 比较对象 | 使用边界 |
| --- | --- | --- |
| 音高差异 | 换声前后的生成歌声，在共同有声区间对齐后比较 | 报告中位音分差、八度错误和有声区间覆盖；F0 提取错误需试听 |
| 音节起点与局部延迟 | 换声前后的同一句 | 用于发现分块错位；音色变化会改变包络 |
| 歌词一致性 | 人工核对为主，ASR 为辅 | 歌唱 ASR 本身可能出错；保留人工纠正结论 |
| 说话人相似度 | 转换歌声与目标参考 | 说话参考与歌声有域差异；不设未经标定的统一通过分数 |
| 重混差异 | A 与 B，先核对时间和已知增益 | 不是分离质量的真实 SDR；没有干净真值时不报告真值分离指标 |
| 速度与显存 | 每个模型阶段 | 单独记录下载、首次加载、推理和峰值显存 |

如果引入自动说话人相似度评价，优先采用独立于转换模型内部条件编码器的评价器，避免指标与模型机制过度耦合。首版只用听感完成音色评估也可以，但不能声称已有客观相似度结果。

耗时统一记录 wall time 秒数。RTF 定义为阶段推理耗时除以该阶段实际处理音频时长；数值越小越快。另保存包含模型加载的总耗时。GPU 利用率和显存可以通过外部采样记录，标明采样间隔和进程范围。

听感由至少两位评审独立记录会更稳妥；若只有一位，明确标为单人判断。每项采用 1–5 分并附具体时间点，例如“副歌第一个长音出现双音”或“第二段开头落后伴奏”，不只保存总分。

| 维度 | 要回答的问题 |
| --- | --- |
| 目标风格 | 乐器、节奏和编配是否符合描述 |
| 歌曲保留 | 是否认得原曲旋律，歌词和段落是否正确 |
| 目标音色 | 是否接近参考人物，高低音是否一致 |
| 演唱自然度 | 辅音、气声、长音、转音和真假声是否自然 |
| 混音与同步 | 是否有旧人声残留、双音、错拍、突兀音量或接缝 |

最小对照实验先固定一份 YuE2 输出和一份分离结果，只改变换声因素。

| 实验 | 参考片段 | 推理步数 | 用途 |
| --- | --- | --- | --- |
| E0 | 不换声 | 不适用 | 直接重混 B，建立声音质量基线 |
| E1 | 清晰片段 R1 | 30 | 默认换声配置 |
| E2 | 同一片段 R1 | 50 | 检查增加推理步数是否值得 |
| E3 | 同人物另一片段 R2 | 30 | 检查参考录音选择的影响；有第二段时执行 |

E1 的差异未定位前，不同时更换分离模型、生成 seed、参考片段和推理步数。首个样本跑通后再扩展到至少三首具有不同音域和编配密度的歌曲；这属于后续效果探索，不是首轮最小交付的前置条件。

故障按最早出现的位置处理。

| 症状 | 优先检查 | 后续动作 |
| --- | --- | --- |
| 旋律明显不对 | ABC 转录与 YuE2 A | 修正谱或生成配置，不调换声参数 |
| A 好听，B 明显变差 | 分离残留、声道、归一化与重混增益 | 修正分离或电平处理 |
| B 正常，C 歌词含混 | 源人声纯度、Seed-VC 模型分支和内容保持 | 比较更清晰参考、30／50 步；保留原输出 |
| 高音失真或八度跳变 | 源 F0、和声污染、源与目标音域差异 | 先减少污染；整体移调作为独立后续实验 |
| 目标音色忽近忽远 | 参考质量、长音与分块边界 | 更换同人物清晰参考并检查局部边界 |
| 听到两个歌手 | 伴奏主唱残留、叠唱与混响 | 检查伴奏独听，必要时增加主唱／和声处理 |
| 越唱越错位 | 采样率解释、切片位置、时长调整 | 查时间轴；不靠简单尾部裁剪解决 |
| 纯伴奏段出现声音 | 源人声噪声、转换模型静音行为 | 先检查源轨；如需门限，保留弱起音和尾音并记录 |

最终报告给出技术状态、各维度听感、问题时间点、耗时和建议的下一项单变量实验。只有输出完整且质量判断可追溯时，才把该次运行标为可用 baseline。
