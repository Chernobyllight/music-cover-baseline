# M5 距离 10 分钟的实测差距

本轮对照使用 Torch 2.15、原模型权重、32 步 midpoint 和 30 步 Euler。用户已试听此前提供的片段，并反馈质量可以接受。已成功计时的旧整曲为 48.76 分钟，此前所有候选合计的 16–17 分钟是局部外推。

原账本采用固定授权名 `m5-ten-minute-round` 记录新增 300 秒。重复启动同轮探针沿用该额度。旧记录及其剩余额度单列，全局冷却继续跨轮检查。超时、加载和异常退出均按 worker 生命周期计入用量。模型保持在 MPS，关闭算子回退。性能测试使用同一首歌的存档数据。

## 决策与目标差距

**候选组合仍约 16–17 分钟。** 沿用上一轮 960–1,020 秒估算，仅替换已计入的 23.19 秒语义投影收益，再扣除本轮 Seed-VC 完整求解比例所支持的 2.1–2.4 秒。按两个 KV 端点做情景计算为 **943–1,022 秒**，距 600 秒还差 **343–422 秒**。区间不包含长时间运行的热状态、块间差异和启动波动，不是置信区间。

| 按候选收益排序 | 与本项比较基线相比，预计整曲净省 | 本轮对既有估算的贡献 | 取舍 |
| --- | ---: | ---: | --- |
| YuE2 原生 AR attention 上叠加语义词表投影 | 19–37 秒 | 相比已计入的 23.19 秒，少省约 4 秒至多省约 14 秒 | 保留候选；长 KV 的单批计时有重叠 |
| Seed-VC 广播 key mask 与省去等头数 K/V 复制 | 约 2.1–2.4 秒 | 全部为新增，基线已使用局部 FP16 | 保留可选补丁 |
| YuE2 合并 QKV、合并 gate/up；Seed-VC 复用 CFG 条件 | 各计 0 秒 | 0 秒 | 各自耗时与基线波动重叠 |

按相同歌曲的调用数，YuE2 NAR 的 64 次前向约 **224 秒**。YuE2 AR 回放含采样，每个 token 按短、长 KV 的候选均值外推约 **201–269 秒**。加上准备、转谱、分离和混音的约 **209 秒**，这三项在短 KV 情景下已约 **634 秒**，尚未计入 Seed-VC。Seed-VC 的 FP16 DiT 含本轮改动仍约 **153–180 秒**；此外还有 YuE2 预填充、加载、VAE，以及 Seed 特征和声码器等。此前 BigVGAN 对 20 秒源 mel 的单次解码为 8.47 秒，整曲实际声码器耗时仍需分块验证。209 秒中分离的约 165 秒来自上一轮单块外推。

10 分钟留给两模型合计约 391 秒，当前 YuE2 的 AR 和 NAR 已超过这个量级。5 分钟只余约 91 秒；2–3 分钟还需降低其他阶段的约 209 秒。固定权重、固定步数和目前的串行执行条件下，本轮没有找到能弥补数分钟差距的低侵入改动。

## YuE2 NAR 单层成本

下表以整首形状的真实状态执行完整 velocity，再取第 15 层的输入单独预热计时。整次首次 3.500 秒，预热后 3.498 秒。28 层、64 次前向的列为量级估算。

| 操作 | 单层 ms | 28 层 × 64 次，秒 |
| --- | ---: | ---: |
| Q/K/V 投影、归一化及 RoPE | 16.20 | 29.0 |
| K/V 拼接 | 0.99 | 1.8 |
| attention（含现有分块与 GQA 展开） | 61.33 | 109.9 |
| 输出投影 | 3.40 | 6.1 |
| 完整门控 MLP | 31.86 | 57.1 |

这五项乘以 28 得到约 3.19 秒，比完整前向少 0.31 秒。逐项同步、层间差异、其他归一化、残差与首尾映射都会影响差值。QKV 和 MLP 的约 86 秒是两者全部工作量估算，只有其中一部分可能因合并线性层而消除。

## 合并 NAR 的线性投影

在同一进程、相同完整缓存与声学状态上，28 层同时采用一种候选。分别核对中间层的投影与最终 velocity，再恢复原方法。两种候选都逐值相同。基线在候选前为 3.485 秒、候选后为 3.549 秒。

| 候选 | 一次性打包 | 额外打包权重 | 完整 velocity 预热后 | 取舍 |
| --- | ---: | ---: | ---: | --- |
| 合并 Q/K/V | 0.031 秒 | 448 MiB | 3.510 秒 | 落在前后基线之间 |
| 合并 gate/up | 0.062 秒 | 1,344 MiB | 3.527 秒 | 落在前后基线之间 |

两项均未达到 0.938 秒／次的目标，不进入连续 midpoint 验证。分项 worker 采样到的 MPS driver 峰值为 8.95 GiB，测试合并的 worker 为 9.95 GiB；原权重与打包权重共存，采样周期 0.2 秒。这两项的估算新增节省均记 0 秒。

## Seed-VC 长块筛选

复用 2,580 帧真实输入、CFG 0.7 和已试听的局部 FP16。用 CPU FP32 参考检查两个序列同长以及其中一个有 padding 的可见位置，MPS FP16 广播与稠密 mask 均通过。保留显式非因果 mask。计时覆盖 CFG 输入准备与完整 DiT 单步，独立看每项。每项预热一次后测两次，两端同步 MPS。首尾基线的四次取值为 474.69–475.49 ms，均值 475.12 ms。

| 改动 | 两次单步范围 | 按 330 次单独外推 | 长块输出 |
| --- | ---: | ---: | --- |
| 广播 key mask | 462.14–462.14 ms | 约 4.28 秒 | 逐值一致 |
| 省去等头数 K/V 复制 | 471.83–472.60 ms | 约 0.96 秒 | 逐值一致 |
| 复用静态 CFG 条件 | 473.91–474.91 ms | 约 0.24 秒，落入基线波动 | 逐值一致 |

前两项通过筛选，CFG 复用不进组合。独立结果不可相加。一次共享模型与设备准备为 2.85 秒，该 worker 的 MPS driver 峰值 1.73 GiB。长块测试仅覆盖循环候选中的 CFG 条件准备。

## Seed-VC 完整 30 步

真实乐句含 176 帧源条件与完整的 898 帧参考，使用相同初始噪声、局部 FP16 DiT、FP32 求解状态与 BigVGAN。两路分别用同形状的一步 Euler 和声码器预热。求解均实际执行 30 步；共享加载及设备准备 2.158 秒。

| 每句耗时 | 已试听配置 | 广播 mask 与省去等头数复制 |
| --- | ---: | ---: |
| 单独预热 | 1.108 秒 | 1.046 秒 |
| 完整求解 | 5.277 秒 | 5.207 秒 |
| FP32 声码器 | 0.866 秒 | 0.860 秒 |

求解节省 70 ms，约 1.33%。按此前 155–182 秒的整曲 FP16 DiT 估算，对应 **2.1–2.4 秒**。同一进程先运行基线，末位毫秒受热状态与执行顺序影响；各块长度不同，短句比例仅作估算。声码器不计加速。组合 worker 的 MPS driver 峰值 1.86 GiB；两项改动均复用原权重。

两路均为 44.1 kHz、90,112 个样本，峰值 0.9969135。30 步源 mel 的最大绝对误差和相对 RMS 误差全部为零。两路解码 PCM 与此前获认可片段逐样本相同，135 帧共同有声，F0 最大差 0 音分。这项验证覆盖同一真实乐句，整曲跨块与热降频尚待实测。

历史实验的本地试听文件位于 `runs/probes/mps-performance/`。本轮对照和组合分别是 `18_seed-combo/fp16-baseline.wav` 和 `18_seed-combo/fp16-candidate.wav`，此前试听的 FP16 片段是 `13_seed-phrase/fp16.wav`。

## YuE2 真实 AR 回放

Torch 2.15 BF16。两路共享原生 GQA 预填充的真实 KV，每段回放 8 个已知 token，采用原语义分布、CPU 抽样和下一 token 的 MPS 传输。每种方法先做独立的数值回放，再按完整头、压缩头、压缩头、完整头顺序计时。以下为两批计时的均值。压缩头对原权重取连续视图，未复制一份输出层权重。

| KV 长度 | 同模型完整词表，每 token | 同模型允许行，每 token | 差值 × 5,122 |
| --- | ---: | ---: | ---: |
| 2,759 | 46.53 ms | 39.24 ms | 37.37 秒 |
| 7,864 | 56.26 ms | 52.46 ms | 19.47 秒 |

短、长各 8 步的允许位置 logits、全词表概率、greedy 与固定种子的随机 token、末尾 RNG 状态一致。长 KV 完整头两批为 54.31、58.21 ms，压缩头为 55.21、49.71 ms，存在顺序与热状态波动。本次只验证固定 token 回放；EOS 的边界用例见上一轮。一次共享模型加载及设备准备 4.55 秒，两次上下文预填充分别 1.81、3.87 秒，均单列。MPS driver 峰值 8.17 GiB。语义头诊断只替换本进程的模型方法，退出即恢复。未更改 ABC 路径或默认生成。

## 预算与核验

## 复现旧 main 实验

从仓库根目录执行。命令需要旧 `main` 的原始成功运行快照，以及原始 `runs/probes/mps-performance/budget.json` 账本。两项均为本地实验产物。探针使用旧阶段名和产物路径，适用于该历史快照。日常 v1.2 生成和预检见 [Mac 使用说明](09-macos.md)。Round 4 使用对应的 Torch 2.15 环境。

```bash
run=runs/20261117_165850_tonight_awake_folk_f9176f
ledger=runs/probes/mps-performance
envs/control/bin/python scripts/diagnostics/profile_mps.py nar-cost --run "$run" --output "$ledger" --deadline 60
```

其他组通过同一命令的 mode 运行。每次先读已有数据；相邻 worker 之间至少冷却 300 秒。候选加载到进程内或临时源码副本，退出即恢复。正常安装和正式 CLI 使用原选项。

分组 mode 依次为 `nar-cost`、`nar-fuse`、`seed-cost`、`seed-combo`、`ar-combo`。若要只复核本轮音频，可直接在 CPU 执行以下命令。

```bash
envs/seed-vc-torch215/bin/python scripts/diagnostics/profile_seed_phrase.py compare "$ledger/18_seed-combo" --names fp16-baseline fp16-candidate --accepted "$ledger/13_seed-phrase/fp16.wav"
```

Seed-VC 的两份可选补丁已在固定 commit 的临时检出上验证重复应用和撤回。仅在单独的候选检出中需要实际应用时使用以下命令。诊断本身在临时副本应用，主工作树无需撤回。

```bash

# 撤回上述两个选项，保留原有适配补丁

```
